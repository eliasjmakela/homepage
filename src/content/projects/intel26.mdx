## What it is

An emulator for the Intel 8080, the 8-bit microprocessor from 1974 that ran
many early arcade machines.

## How it's built

C# and .NET.

## Where it's at

Set aside since 2022 because of work. The goal is still to implement the
processor and all the peripheral components needed to run an original Space
Invaders cabinet.
